# Tarea 1

En esta tarea aplicarás el framework de formulación de proyectos que revisamos en clase (Materiales 01 y 02) a un problema real.
Para eso, explorarás la plataforma **Solve for Good**, que publica proyectos reales de organizaciones sin fines de lucro e instituciones que
buscan usar ciencia de datos para resolver problemas de impacto social.

> Se evaluará su capacidad para pensar en el problema con claridad, identificar metas accionables y razonar sobre qué datos y análisis serían relevantes.

### Paso 2. Formula el proyecto usando el framework de *scoping*

Usando el modelo de los pasos que revisamos en el Material 02, responde las siguientes preguntas para el proyecto que elegiste. Sé lo más específico posible.

#### 0. Identificación del problema

- ¿Cuál es el problema real?
- ¿A quiénes afecta? ¿A cuántas personas afecta?
- ¿Por qué la organización lo considera una prioridad?

#### 1. Meta

- ¿Cuál es el resultado **concreto, específico y medible** que se busca alcanzar?
- ¿Cómo sabrías que el proyecto tuvo éxito?
- La meta **NO** es construir un modelo, hacer un mapa o un dashboard. El modelo es el medio, no el fin.

#### 2. Acción

- ¿Qué acción, programa o intervención implementaron? S
- ¿Quién ejecuta la acción? ¿Sobre quién o qué se toma la acción? ¿Con qué frecuencia?

#### 3. Datos

- ¿Qué datos necesitarías para resolver el problema?
- ¿Qué tipo de información contienen? (individuos, lugares, transacciones, texto, imágenes...)
- ¿Cuáles serían las limitaciones o riesgos de usar esos datos?
    - > No necesitas saber exactamente qué bases de datos existen. Piensa en qué información necesitarías **idealmente** para resolver el problema.

#### 4. Análisis

- ¿Qué tipo de análisis realizaron o sería necesario?
- ¿Cómo informaría ese análisis la **acción** que identificaste en el paso anterior?

#### 5. Ética y consideraciones finales

- ¿Qué consideraciones éticas identificas en este proyecto?
- Reflexiona sobre privacidad, equidad, posibles sesgos o impactos no deseados en la población afectada.


### Paso 3. Reflexión final

Responde brevemente (máximo 1/3 página en total):

- ¿Qué fue lo más difícil de definir? ¿Por qué?
- ¿Crees que el proyecto es accionable tal como está planteado en la plataforma? ¿Qué cambiarías o qué información adicional necesitarías?


### Toma en cuenta

- No elijas el proyecto más técnico: elige el que más te permita razonar sobre el problema y las personas afectadas.
- Si la descripción del proyecto en la plataforma es vaga, **puedes hacer suposiciones razonables**. Explícalas.
- Existen proyecto mal planteados, replantéalos considerando el material visto en clase. 
- Recuerda la distinción del Material 01: ciencia de datos no pregunta *por qué falla el sistema*, sino *dónde actuar primero*.

## Rúbrica

Cada sección del framework tiene el mismo peso. La reflexión final se evalúa en función de la profundidad de las secciones que comentes.

| Sección | Excelente (100%) | Suficiente (70%) | Insuficiente (40%) |
|---|---|---|---|
| **0. Problema** | Describe claramente el problema, quiénes son afectados y por qué es una prioridad. | Menciona el problema pero le falta precisión o contexto. | No queda claro cuál es el problema real. |
| **1. Meta** | Meta concreta, específica y medible. Se entiende qué cambiaría si el proyecto tiene éxito. | La meta existe pero es demasiado vaga o abstracta. | La meta confunde el análisis técnico con el objetivo real. |
| **2. Acción** | Acción realista e identificada: quién la ejecuta, sobre quién, con qué frecuencia. | Acción mencionada pero poco operacionalizada. | No hay acción clara o el análisis es el objetivo. |
| **3. Datos** | Identifica fuentes concretas con granularidad, tipo y consideraciones éticas. | Menciona datos pero de forma genérica. | No se especifican datos o son irrelevantes al problema. |
| **4. Análisis** | Tipo de análisis justificado y vinculado a la acción. | Menciona análisis pero sin justificación. | No hay análisis propuesto o no tiene sentido para el problema. |
| **5. Ética** | Identifica al menos una consideración ética relevante y específica. | Mención superficial de ética. | No hay reflexión ética. |

*Basado en el framework de Rayid Ghani y Kit Rodolfa — Machine Learning in Practice, Carnegie Mellon University.*
